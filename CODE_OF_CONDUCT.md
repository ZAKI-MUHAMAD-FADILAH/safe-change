# Code of conduct

## Our standards

Project participation must remain professional, respectful, and focused on improving software safety. Constructive technical disagreement is welcome. Harassment, discrimination, threats, doxxing, disclosure of private information, and intentionally disruptive behavior are not accepted.

## Security and privacy

Never post credentials, private source code, personal data, or unredacted vulnerability details in public project channels. Follow [SECURITY.md](SECURITY.md) for vulnerability reporting.

## Enforcement

Maintainers may edit or remove contributions and restrict participation when behavior violates these standards. Report conduct concerns privately to the repository maintainer through their GitHub profile. Reports will be reviewed as confidentially as reasonably possible.

## Scope

This policy applies to repository discussions, issues, pull requests, reviews, release channels, and project-related public interactions.
